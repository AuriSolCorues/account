# 账号本子：前端页面设计

## JPG 风格补充规范（当前版本）

本节以 `2CFB643D27E9D29E6E3BDF16BC109263.jpg`、`ligit832A165A77FF.jpg`、`53B575396C14BB4B118847DDC3714179.jpg` 和 `BE6860E44093C780B98DE584ABD95AF2.jpg` 为视觉参考，优先级高于早期 SVG/PNG 颜色示意。

- 首页采用“大留白、扁平列表”布局：顶部整宽绿色栏，内容区使用近黑或白色背景，减少账号卡片边框和阴影。
- 分组列表使用较大字号和较宽垂直间距；当前分组使用绿色文字或浅色底高亮，分组过多时横向滑动并保留字母索引。
- 标签管理使用纯列表行，拖动手柄放在右侧；底部固定绿色圆角按钮“添加新标签”。
- 设置页使用深色圆角设置块，右侧显示开关、数值或箭头；清空本地数据等危险操作使用红色。
- 账号详情使用底部弹层，顶部放置编辑、收藏、删除操作，内容按字段纵向排列。
- 动态密码使用当前主题的正常主文字色，倒计时使用辅助文字色；黄色只用于真正的提醒，不用于验证码。
- 绿色主题沿用 JPG 的深绿顶栏、近黑背景、深灰设置块和绿色开关；蓝色主题作为独立备用配色，不改变布局。
- 长按自定义分组后，行浮起、放大、加阴影并跟随手指移动，其他行平滑让位，松手后动画落位。

## 设计原则

- 深色优先，低干扰、高对比；浅色和跟随系统沿用相同层级与语义色。
- 账号名称可见，密码、恢复码和 TOTP 密钥默认永不直接展示；仅提供复制或按住显示。
- 所有敏感操作有即时、简短的反馈，不使用会遮挡验证码的长提示。
- 延续账号本子的账本式主界面：左侧常驻纵向分组，右侧账号列表。它优先于 Material 3 常见的横向标签和底部导航，降低旧用户的迁移成本。

## 信息架构

```
解锁
  └─ 首页
      ├─ 账号详情 ─ 编辑账号 ─ TOTP 扫码导入
      ├─ 新建账号
      ├─ 分组管理
      ├─ 安全日志
      └─ 设置 ─ WebDAV 与备份
```

已解锁后直接进入双栏首页：左侧分组栏、右侧账号列表；不使用底部导航。安全日志和设置放在左侧栏底部，账号详情、编辑、扫码和 WebDAV 均为全屏二级页面，顶部有返回按钮。

## 1. 解锁页

```
┌─────────────────────────────────┐
│          账号本子                 │
│          本地加密保存             │
│                                 │
│                                 │
│        ┌─────────────────┐       │
│        │      ◉ 指纹      │       │
│        │  请验证身份以解锁 │       │
│        │                 │       │
│        │       取消       │       │
│        └─────────────────┘       │
│                                 │
│                                 │
│          使用主密码               │
└─────────────────────────────────┘
```

- 若已启用生物识别，应用打开后立即唤起 Android 系统指纹验证弹窗；这是默认且优先的解锁方式。弹窗提供文字按钮“取消”。
- 点击“取消”、指纹不可用或连续识别失败后，显示简洁的“使用主密码”文字入口；点按后才展开主密码输入框和“解锁”按钮。主密码默认隐藏输入，支持显示切换和回车解锁。
- 指纹验证与主密码失败统一只显示“无法解锁”，不泄露失败原因或数据状态细节；可再次使用指纹或主密码重试。

首次使用改为两步：输入主密码 → 再次确认；确认后可选开启生物识别。

## 2. 首页（账号）

```
┌─────────────────────────────────┐
│ 账号本子           ＋  ⌕  ☰      │
│──────────┬──────────────────────│
│ 默认     │ GitHub             ⋮  │
│ 动态密码 │ hexo · 工作            │
│          │──────────────────────│
│ 社交媒体 │ Gmail              ⋮  │
│ 游戏娱乐 │ name@example.com · 生活│
│ 银行卡   │──────────────────────│
│ 工作     │ NAS                ⋮  │
│──────────┴──────────────────────│
│ ⚙ 设置       安全日志             │
└─────────────────────────────────┘
```

- 顶部操作固定为新增、搜索和更多菜单，延续旧应用的高频操作位置；搜索展开后自动聚焦，结果高亮匹配文字，敏感字段不在列表显示内容。
- 左栏固定顺序为“默认、动态密码、自定义分组”；安全日志和设置固定在底部。所有分组名称均可自定义，但默认和动态密码的位置及系统行为不可改变。
- 默认分组显示没有任何自定义分组的账号；动态密码是系统派生筛选，显示所有配置了 TOTP 的账号，不作为普通分组关联保存。
- 用户分组可在“分组管理”中新增、改名、删除和长按拖动排序；删除账号最后一个自定义分组后，账号自动回到默认分组。
- 轻点分组立即筛选；长按一个或多个分组进入多选，结果为交集。动态密码可与自定义分组组合筛选。
- 右侧列表显示账号名称和非敏感副标题；最右保留字母索引以快速跳转，不显示密码或验证码。
- 从当前选中的自定义分组新建账号时，编辑页预选该分组并在保存后自动加入；选中默认时保持未分组；选中动态密码时不建立普通分组关联，只有配置 TOTP 后才显示在该分组。无明确分组上下文（如搜索结果）中新建按默认处理。
- 默认分组和动态密码分组均提供独立空状态：默认提示“暂无未分组账号”，动态密码提示“在账号编辑页添加两步验证”。
- 改名使用简洁对话框；只修改显示名称，不改变默认/动态密码的固定标识、位置和筛选逻辑。
- 点击账号条目打开底部速览面板；点击遮罩空白处或向下滑关闭。速览是快速复制入口，只有“查看详情”和“编辑”才进入需要返回按钮的二级页面。
- 速览中用户名、动态验证码的整行文本与复制按钮都直接复制。密码默认掩码：点击掩码文本显示明文，点击明文文本复制；右侧复制按钮不受掩码状态影响，始终复制明文。关闭速览后恢复掩码。
- 长按账号弹出操作菜单：作为模板新建、复制账号全部可复制内容、编辑、删除；复制全部内容会逐字段写审计日志但不记录字段值。
- 选中“动态密码”时右栏显示所有已配置 TOTP 的账号和倒计时；没有 TOTP 账号时显示空状态提示。

- 密码默认掩码；点击掩码显示明文，关闭当前页面或速览后恢复掩码。详情页密码文本在明文状态下点击即可复制，复制按钮始终直接复制明文。

```

│ ‹  分组管理              ＋ 新增  │
│                                 │

│   默认                    24     │

│                                 │
│ 自定义分组                       │

│                                 │

```

- 顶部：返回、标题“分组管理”和“新增分组”。
- 固定分组区显示默认和动态密码；二者不可删除、拖动或改变系统行为，但均可点按改名。

- 左栏中的分组顺序与此页即时保持一致。

- 顶部：返回、标题“新建账号/编辑账号”、保存。

- 删除账号置于页尾的危险区域，二次确认弹窗只显示账号名称，不展示敏感值。

## 8. WebDAV 与备份页

```
┌─────────────────────────────────┐
│ ‹  WebDAV 与备份                 │
│                                 │
│ WebDAV 连接                       │
│ 服务器 [https://dav.example]     │
│ 用户名 [hexo                  ]  │
│ 应用密码 [••••••••••          ]  │
│ 远程目录 [/backup             ]  │
│          [测试连接]               │
│                                 │
│ 完整加密备份（.acc）              │
│ [导出备份]  [从 .acc 恢复]        │
│ 最近成功：今天 10:20              │
└─────────────────────────────────┘
```

- 连接配置：服务器地址、用户名、应用密码、远程目录；密码输入始终隐藏。
- 操作顺序固定为“测试连接”→“上传完整 `.acc` 备份”或“下载 `.acc` 并恢复”，避免将恢复与下载混为一步。
- 显示最近一次成功备份时间、文件名和结果；失败只给出可行动的原因，例如认证失败或网络不可用。
- 导出说明显示：`.acc` 根节点只有加密的 `passwordVault` 和明文可编辑的 `appSettings`；不包含 WebDAV、设备生物识别和安全日志。
- `.acc` 恢复先要求备份主密码，再显示账号去重结果和已应用的软件设置；旧版 v13 明文导入仅导入账号数据，且不覆盖本地已有账号。

## 交互与无障碍要求

- 所有图标按钮提供文字内容描述；仅靠颜色不传递状态。
- 验证码、密码掩码与关键时间使用足够大的字号和对比度。
- 删除、恢复、替换 TOTP、清空日志均需要二次确认。
- 应用锁定后立即移除敏感页面状态；重新解锁后回到首页，不恢复编辑中的敏感输入。
