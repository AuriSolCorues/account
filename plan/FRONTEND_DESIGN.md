# 账号本子：前端页面设计

## JPG 风格补充规范（当前验证版）

本节以 `2CFB643D27E9D29E6E3BDF16BC109263.jpg`、`ligit832A165A77FF.jpg`、`53B575396C14BB4B118847DDC3714179.jpg` 和 `BE6860E44093C780B98DE584ABD95AF2.jpg` 为视觉参考，优先级高于早期 SVG/PNG 颜色示意。

- 首页采用“大留白、紧凑卡片”布局：顶部整宽绿色栏，内容区使用近黑或白色背景，账号卡片保留轻量背景但减少边框、阴影和内部留白。
- 分组栏按窗口可用宽度自适应，保持至少约三个中文字的可读空间，不横向滑动；超长名称单行省略显示，当前分组使用绿色文字或浅色底高亮。
- 标签管理使用纯列表行，拖动手柄放在右侧；底部固定绿色圆角按钮“添加新标签”。
- 设置页使用深色圆角设置块，右侧显示开关、数值或箭头；清空本地数据等危险操作使用红色。
- 账号详情使用底部弹层，顶部放置编辑、收藏、删除操作，内容按字段纵向排列。
- 动态密码使用当前主题的正常主文字色，倒计时使用辅助文字色；黄色只用于真正的提醒，不用于验证码。
- 绿色主题沿用 JPG 的深绿顶栏、近黑背景、深灰设置块和绿色开关；蓝色主题作为独立备用配色，不改变布局。
- 长按自定义分组后，行浮起、放大、加阴影并跟随手指移动，其他行平滑让位，松手后动画落位。

## 可交互页面与控件预览

在浏览器中打开 [theme-preview.html](theme-preview.html) 查看当前验证版：覆盖解锁、首页默认/动态密码、分组管理、账号详情、新建编辑、设置、加密备份与控件规范；默认使用深色绿色主题，也可切换浅色和蓝色配色。需要全局对照页面与交互路径时，查看 [UI_ALL_SCREENS.svg](UI_ALL_SCREENS.svg)。

该 HTML 只作视觉与组合验证，不锁定最终页面。编辑页两列字段行与底部字段窗口已接入 Android，仍待真机交互复验；扫码、安全日志和 WebDAV 不在当前版本范围内。

## 设计原则

- 深色优先，低干扰、高对比；浅色和跟随系统沿用相同层级与语义色。
- 账号名称可见，密码、恢复码和 TOTP 密钥默认永不直接展示；仅提供复制或按住显示。
- 所有敏感操作有即时、简短的反馈，不使用会遮挡验证码的长提示。
- 延续账号本子的账本式主界面：左侧常驻纵向分组，右侧账号列表。它优先于 Material 3 常见的横向标签和底部导航，降低旧用户的迁移成本。

## 信息架构

```
解锁
  └─ 首页
      ├─ 账号详情 ─ 编辑账号 ─ 手动输入 TOTP
      ├─ 新建账号
      ├─ 分组管理
      └─ 设置 ─ 加密备份
```

已解锁后直接进入双栏首页：左侧分组栏、右侧账号列表；不使用底部导航。首页右上角三条横杠进入设置，左侧栏底部仅保留分组管理；账号详情、编辑和加密备份均为全屏二级页面，顶部有返回按钮。

## 1. 解锁页

```
┌─────────────────────────────────┐
│          账号本子                 │
│          本地加密保存             │
│                                 │
│                                 │
│        ┌─────────────────┐       │
│        │      ◉ 指纹      │       │
│        │  请验证身份以解锁 │       │
│        │                 │       │
│        │       取消       │       │
│        └─────────────────┘       │
│                                 │
│                                 │
│          使用主密码               │
└─────────────────────────────────┘
```

- 若已启用生物识别，应用打开后立即唤起 Android 系统指纹验证弹窗；这是默认且优先的解锁方式。弹窗提供文字按钮“取消”。
- 点击“取消”、指纹不可用或连续识别失败后，显示简洁的“使用主密码”文字入口；点按后才展开主密码输入框和“解锁”按钮。主密码默认隐藏输入，支持显示切换和回车解锁。
- 指纹验证与主密码失败统一只显示“无法解锁”，不泄露失败原因或数据状态细节；可再次使用指纹或主密码重试。

首次使用改为两步：输入主密码 → 再次确认；确认后可选开启生物识别。

## 2. 首页（账号）

```
┌─────────────────────────────────┐
│ 账号本子           ＋  ⌕  ☰      │
│──────────┬──────────────────────│
│ 默认     │ GitHub                  │
│ 动态密码 │ hexo · 工作             │
│          │────────────────────────│
│ 社交媒体 │ Gmail                   │
│ 游戏娱乐 │ name@example.com · 生活 │
│ 银行卡   │────────────────────────│
│ 工作     │ NAS                     │
│──────────┴────────────────────────│
│ ⚙ 分组管理                         │
└─────────────────────────────────┘
```

- 顶部操作固定为新增、搜索和设置（三条横杠），延续旧应用的高频操作位置；搜索展开后自动聚焦，结果高亮匹配文字，敏感字段不在列表显示内容。
- 左栏固定顺序为“默认、动态密码、自定义分组”；底部仅保留分组管理。所有分组名称均可自定义，但默认和动态密码的位置及系统行为不可改变。
- 默认分组显示没有任何自定义分组的账号；动态密码是系统派生筛选，显示所有配置了 TOTP 的账号，不作为普通分组关联保存。
- 用户分组可在“分组管理”中新增、改名、删除和长按拖动排序；删除账号最后一个自定义分组后，账号自动回到默认分组。
- 轻点分组立即筛选；长按一个或多个分组进入多选，结果为交集。动态密码可与自定义分组组合筛选。
- 右侧使用紧凑卡片，仅显示账号名称和非敏感副标题两行；移除头像、2FA 标签和右侧菜单图标，不显示密码或验证码。
- 账号模型预留可选 `iconKey`，当前为空时不显示图标，继续使用现有文字内容；未来只增加 `iconKey` 到图标资源的渲染映射，不改变账号数据和页面导航。
- 设计图中的像素尺寸只用于比例参考；实现统一使用 `dp/sp`、窗口约束、权重、最小/最大宽度和滚动，适配不同尺寸手机。
- 从当前选中的自定义分组新建账号时，编辑页预选该分组并在保存后自动加入；选中默认时保持未分组；选中动态密码时不建立普通分组关联，只有配置 TOTP 后才显示在该分组。无明确分组上下文（如搜索结果）中新建按默认处理。
- 默认分组和动态密码分组均提供独立空状态：默认提示“暂无未分组账号”，动态密码提示“在账号编辑页添加两步验证”。
- 改名使用简洁对话框；只修改显示名称，不改变默认/动态密码的固定标识、位置和筛选逻辑。
- 点击账号条目打开底部速览面板；点击遮罩空白处或向下滑关闭。速览是快速复制入口，只有“查看详情”和“编辑”才进入需要返回按钮的二级页面。
- 速览中用户名、动态验证码的整行文本与复制按钮都直接复制。密码默认掩码：点击掩码文本显示明文，点击明文文本复制；右侧复制按钮不受掩码状态影响，始终复制明文。关闭速览后恢复掩码。
- 长按账号弹出操作菜单：作为模板新建、复制账号全部可复制内容、编辑、删除。
- 选中“动态密码”时右栏显示所有已配置 TOTP/Steam Guard 的账号和倒计时；卡片顶部使用按剩余时间持续缩短的横线表示周期进度，没有 2FA 账号时显示空状态提示。账号卡片保持紧凑高度，周期结束后恢复满宽并刷新验证码。

## 4. 新建与编辑账号页

字段采用“两列一行”版式：左列是键名（可点），右列是值输入框（可直接编辑）。用户名、密码、网址、恢复码、备注等全部是同一款行；行上不堆按钮，细项放弹出的“单条字段编辑窗口”。

```
┌─────────────────────────────────┐
│ ‹  编辑账号                  保存 │
│ 名称 [ GitHub                 ]  │
│ 分组 [工作] [开发]             › │
│                                 │
│ 用户名  [hexo@…               ]   │
│ 密码    [•••••••         显示]   │
│ 网址    [https://…            ]  │
│ 恢复码  [•••••••         显示]   │
│ 备注    [……                   ]  │
│ [排序][删除][随机密码][＋新增字段] │
│                                 │
│ 两步验证                 已配置 › │
│                                 │
│               删除账号             │
└─────────────────────────────────┘
```

- 顶部：返回、标题“新建账号 / 编辑账号”、右上角「保存」。首段：名称（必填）、分组多选；新建页按进入时选中的分组预选（自定义直接加入，默认保持未分组，动态密码不作为普通分组写入）。
- **两列字段行**：左列键名（用户名 / 密码 / 网址 / 恢复码 / 备注…）固定宽、过长省略、**整列可点**；右列值输入框可直接快速改值——隐藏型（如恢复码）默认掩码、框内「显示/隐藏」可切明文；用户名不提供「清空」按钮。用户名 / 密码是固定行：不可整行删除、不参与排序。
- **点左侧键名 → 从底部滑出“单条字段编辑窗口”**（样式同账号速览面板），集中编辑这一条：
  - 顶栏：左侧标题 + **右上角「保存」**；下滑 / 点空白 / 返回关闭则不保存。
  - 键名输入框（预填当前名）：自定义字段直接改这一条；用户名 / 密码改的是账号保存的可选显示名（留空回到默认“用户名 / 密码”），保存后详情页与速览同步显示。
  - 「隐藏文本」开关 / 滑块（仅自定义字段出现；用户名固定关、密码固定开）：拨开＝保存为隐藏型（如恢复码），值掩码；内容输入框在开关开时默认掩码、框内「显示/隐藏」可预览。
  - **「随机」按钮仅在“隐藏文本”拨开时出现**，点它就地生成填入正在编辑的这一条。
- **新增字段**：工具条「＋新增字段」＝打开同一个编辑窗口（键名留空、隐藏文本默认关）；填好键名与内容、或拨开隐藏文本后点「随机」，点右上角「保存」，新行落到列表末尾并自动成为“当前字段”。
- **工具条（字段列表下方、两步验证上方）＝ 排序 / 删除 / 随机密码 / ＋新增字段**：
  - 「排序」「删除」是两种**互斥模式**，再点一次或换点另一个即退出：排序态下每行最左出现 ☷ 抓手、长按拖动换序（用户名 / 密码不参与）；删除态下每行最右出现「删除」、点它整行删除（键＋值，用户名 / 密码行不出现）。**整行删除仅此一个入口**，编辑窗口内不放第二个删除。
  - 「随机密码」：弹出随机密码生成面板，「复制并填入」回填到**“当前字段”**——最后点过右侧输入框的那一行（明文 / 隐藏都行，用户名除外）；刚新增的字段自动是当前字段；一进页面未点过任何输入框时默认主密码。与窗口内「随机」（只管正在编辑的这条）分工不同。
- **文字操作的图标位**：所有文字按钮保留可选的前置或后置 Material Vector 图标位（含保存、排序、删除、随机密码、新增字段、导入、导出）；文字始终可见，不改为纯图标按钮。接入图标时必须提供内容描述，避免改变现有点击区域和语义。
- “两步验证”区域仅支持一个 2FA：Google TOTP 或 Steam Guard，编辑周期、算法和位数；支持 `otpauth://`/Base32 与 Steam Base64 shared_secret，不显示密钥。
- 删除账号置于页尾危险区域，二次确认弹窗只显示账号名称，不展示敏感值。
- 数据兼容：用户名 / 密码仍为账号顶层固定字段（不进字段列表），仅为它们新增“可选显示名标签”，旧数据零迁移。

## 5. 设置页

```
┌─────────────────────────────────┐
│ ‹  设置                          │
│                                 │
│ 安全                             │
│ 自动锁定                 5 分钟 › │
│ 生物识别                      开 › │
│ 修改主密码                     ›  │
│                                 │
│ 剪贴板                           │
│ 自动清除               30 秒   › │
│ 外观                     深色   › │
│                                 │
│ 加密备份                       › │
│ 关于                           › │
└─────────────────────────────────┘
```

- **安全**：自动锁定时长、生物识别、修改主密码。
- **安全**：允许截图开关默认关闭，切换后立即生效。
- **剪贴板**：敏感内容自动清除支持关闭、15/30/60 秒预设及 1-86400 秒自定义输入。
- **外观**：深色、浅色、跟随系统。
- **数据与备份**：导出完整 `.acc` 加密备份、从 `.acc` 恢复。
- 导出不显示密码输入框，直接使用当前主密码派生的密钥；弹窗提醒用户记住主密码。
- 恢复先选择 `.acc` 文件，再输入该文件对应的 4-20 个字符备份密码，通过认证后再显示确认对话框；取消或失败不修改当前数据。
- 文件读写使用系统 `CreateDocument`/`OpenDocument` 选择器，由用户授予单文件权限；Android 14 不申请对普通文件无效的广泛存储权限。
- 复制按钮直接写入系统剪贴板；无需申请不存在的“剪贴板权限”，敏感内容按设置的时间（关闭或 1-86400 秒）仅在未被替换时清除。
- **关于**：应用版本与开源许可（如后续引入）。

## 6. 加密备份页

```
┌─────────────────────────────────┐
│ ‹  加密备份                       │
│                                 │
│ 本地加密备份                      │
│ 导出使用当前主密码，不再输入密码   │
│ [导出加密备份 .acc]               │
│ [从 .acc 恢复]                    │
└─────────────────────────────────┘
```

- `.acc` 根节点严格只有 `passwordVault` 和 `appSettings`；前者为 Base64 的 AES-GCM 密文，后者保存可读软件设置。
- 当前版本不提供安全日志、二维码扫描和 WebDAV 页面或入口。
