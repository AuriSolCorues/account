# 手机端“账号本子”交互实测记录（研究参考）

## 说明

本记录来自 Android 真机上的已安装应用，观察对象为包名 `com.wei.account`。
用户提供的 `fcom.wei.account` 在设备上不存在；设备同时安装了本项目的 `com.example.account`。

本记录只整理公开界面和操作逻辑，用于当前版本的初步验证；它不是本项目最终视觉规范，也不要求复制原应用界面。
本项目后续可以整体更换布局、配色和组件，只要保留业务接口即可。不复制原应用的源码、图标、图片资源、数据库或加密实现。

## 真机环境

- 设备：OPPO PJF110
- 屏幕截图分辨率：1080 × 2414
- 应用固定竖屏
- 顶部状态栏与应用绿色标题栏连成一体

## 首页布局

```text
┌─────────────────────────────────────────┐
│ 账号本子                         ＋  搜索  菜单 │
├────────────────┬────────────────────────┤
│ 动态密码       │ ● 微信（Demo）          │
│ 全部账号       │   WeiXin                │
│ 我的收藏       │                        │
│ 社交媒体       │                        │

│ 银行卡         │                        │
│ ⚙              │                  A-Z   │
└────────────────┴────────────────────────┘
```

- 在本次 1080×2414 截图中，顶部绿色栏约占屏幕高度 12.5%，左侧分类栏约占内容宽度 37%，分类项约占内容高度 7.3%；这些是比例参考，不是实现时的固定像素。
- 右侧账号列表从左栏之后开始，右边预留字母索引区域；不同屏幕使用可用宽度、窗口比例和最小可读宽度重新计算。
- 账号行显示两行文字：账号名称和账号副标题。
- 账号行没有必须的头像；左侧可以显示收藏状态的小标记。
- 当前项目继续使用现有文字和 Material 组件，不引入原应用图标；最终视觉设计另行确定。

## 自适应尺寸约定

- 所有页面使用 `dp`、`sp`、系统安全区和 Compose 约束，不使用 1080×2414 等固定像素。
- 首页左栏按可用窗口宽度计算，并限制在可读的最小/最大宽度；超长分组名称单行省略。
- 右侧账号列表使用剩余空间和权重，卡片内容可以换行或滚动，不依赖固定屏幕宽度。
- 顶部栏、底部面板和编辑页根据窗口高度使用比例约束；面板内容较长时依靠拖动和滚动查看。
- 双栏在窄窗口仍保持左栏加右栏；如果以后支持平板或横屏，可在同一套窗口约束下扩展，不改变数据结构。

## 顶部菜单

点击右上角菜单进入设置页。实测设置项包括：

- 账号本子会员
- WebDAV 云同步
- 导出数据
- 导入数据
- 修改密保
- 更多功能
- 帮助中心
- 关于我们

当前项目只吸收“菜单进入设置”的位置关系，不实现会员、日志或 WebDAV。

## 账号长按操作

长按账号行后从底部弹出操作面板：

```text
┌─────────────────────────────────────────┐
│ 编辑        收藏                         删除 │
├─────────────────────────────────────────┤
│ 作为模版新建账号                          │
│ 复制账号全部内容                          │
│ 取消                                      │
└─────────────────────────────────────────┘
```

- 编辑、收藏、删除使用顶部三个等宽操作区域。
- 模板新建和复制全部内容是独立的文字操作行。
- 点击遮罩或“取消”关闭面板。
- 当前项目只把这些操作作为交互验证样本，继续使用自己的按钮、布局和安全确认流程。

## 新建/编辑账号页

每个字段都是同样的三段式结构：

```text
字段名称                         排序  菜单
┌─────────────────────────────────────────┐
│ 请输入…                                 │
└─────────────────────────────────────────┘
```

实测默认字段：名称、账号、密码、备注、标签。

底部操作：

- 绑定动态密码
- 添加新的字段
- 固定底部“保存”按钮

字段菜单包含：

- 在下方插入新字段
- 填入随机密码
- 删除此字段
- 取消

当前项目的密码生成器只验证“从编辑页进入、完成后回填”的业务流程；最终入口位置和视觉组件可重新设计。

## 随机密码生成器

实测面板标题为“随机密码生成器”，右上角为“刷新”：

```text
┌─────────────────────────────────────────┐
│ 随机密码生成器                     刷新   │
├─────────────────────────────────────────┤
│             G6dcN47qNPhE8pvKQmjSYWsRnGay │
│                                         │
│ 长度：28                 ───●────         │
│ 大写字母（A → Z）                 开关   │
│ 小写字母（a → z）                 开关   │
│ 常用数字（2 → 9）                 开关   │
│ 特殊符号（$%&^*()[].@#_!）        开关   │
│ 易混字符（10iolIOL）               开关   │
├─────────────────────────────────────────┤
│              复制并填入                  │
└─────────────────────────────────────────┘
```

当前版本调整为：

- 长度范围 4-20。
- 默认允许易混字符，不过滤 `0/O`、`1/I/l` 等字符。
- 保留大写、小写、数字、特殊符号四类开关。
- 不显示密码强度。
- “复制并填入”同时写入剪贴板并回填当前密码字段；后续可继续保留单独“仅填入”行为。
- 生成器复用账号详情面板的底部面板壳，支持拖动和滚动。

## 当前项目的扩展约定

- 账号模型预留可选 `iconKey` 字段，默认空值，不影响现有 `.acc` 数据。
- 当前界面不显示新图标，继续显示现有账号文字内容。
- 后续设计图标时，只需要增加 `iconKey -> 图标资源/矢量图` 的渲染映射，不改账号数据结构和页面导航。
- 不复制原应用的图标资源；当前项目仍使用自己的占位内容和 Material 组件。
- 页面尺寸只通过窗口约束、权重、最小/最大宽度和滚动决定，后续更换手机或整体换版不需要修改业务模型。
- 账号卡片、详情面板、随机密码生成器都通过独立 Composable 接口连接业务，后续可替换外观而不改变加密、保存和导入导出逻辑。

## 不复制的部分

- 原应用的会员、WebDAV、帮助和日志业务。
- 原应用的数据库结构和旧版加密实现。
- 原应用的图标、图片和品牌资源。
