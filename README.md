# 账号本子 (Account)

个人自用的本地 Android 账号、密码与两步验证（2FA）管理器。应用包名 `com.copy.account`，数据全部保存在本机，不上传任何内容。

## 功能

- **本地加密存储**：AES-256-GCM 加密整个密码库，主密码经 PBKDF2-HMAC-SHA256（300,000 次迭代）派生密钥。
- **解锁**：主密码或设备已注册的指纹/人脸（AndroidKeyStore 不可导出密钥包装）。
- **两步验证**：标准 TOTP（6/8 位、1-300 秒周期、SHA-1/SHA-256/SHA-512）与 Steam Guard；扫 `otpauth://` 二维码自动带出算法、位数、周期与 Steam 参数。
- **受控剪贴板**：复制密码/验证码后按设定时间自动清除，只清除本应用写入的内容。
- **截图保护**：默认开启 `FLAG_SECURE`，禁止截图/录屏/最近任务预览，可在设置中关闭。
- **`.acc` 加密备份**：完整导出/恢复密码库与软件设置，支持手动选择备份目录（SAF）。
- **分组与搜索**：默认/动态密码/自定义分组，长按多选交集筛选，跨名称、分组、字段内容搜索，支持以已有账号为模板新建；搜索框展开即自动聚焦。
- **账号速览**：点账号卡弹底部面板快速复制用户名/密码/验证码，不进详情页；切后台锁定后重新解锁，面板自动恢复到刚才的账号，方便继续复制。
- **自定义主题**：深色/浅色/跟随系统，绿色/蓝色配色，支持 JSONC 格式自定义主题。
- **`appsettings.json` 外挂配置**：可选覆盖层，放在**备份文件夹**里、与 `.acc` 同级（默认 `内部存储/backups/account`），可用文件管理器直接编辑；可覆盖掩码符号、主题、剪贴板时长等。启动不自动读取，在「主题与语言」页手动「重新加载配置文件」，同页常驻一行显示当前生效来源。
- **备份文件夹可自定义**：在「备份与数据」页点「备份文件夹」填内部存储下的相对子路径（如 `Download/账本备份`），留空用默认 `backups/account`；不接受以 `/` 开头的绝对路径和 `..`。
- **系统自动填充**：浏览器/其他应用登录页气泡里逐条列出匹配账号（网址域名优先、应用包名兜底，只显示账号名），点选后指纹验证才回填；也支持把新登录的账号密码保存进密码库。锁定状态下同样先选账号（账号卡只含名称，不含凭据），验证指纹或主密码后单次填充；从未解锁过时出「解锁账号本子」占位卡，验证后按目标匹配填充。

## 安全模型

- 密钥分层：主密码 → KEK → DEK，账号数据用 DEK 加密；生物识别密钥要求每次认证后使用。
- 每次 AES-GCM 加密使用新随机 IV 并校验认证标签，防篡改。
- 密码库单文件 `filesDir/vault.bin` 原子写入，中断不破坏数据。
- 进入后台立即锁定，锁定时清除内存中的密钥与全部明文（含自动填充快照与 DEK 副本）。
- 自动填充通道：解锁后的明文快照仅存本进程内存（AutofillBridge），锁定即清零，Intent 不传明文；每次填充都要验证，Keystore 密钥保持每次必验。锁定态填充为瞬时解封：解出的明文只存在于当次回包构建作用域，不重开快照窗口。
- 锁定态账号卡依赖一份「公开索引」（仅账号名称/网址/包名，无任何凭据字段），以普通 JSON 存于应用沙箱 `filesDir/autofill_public_index.json`；手动关闭填充窗口或关闭自动填充开关会连索引一起清除。

## 数据与文件

| 位置 | 说明 |
| --- | --- |
| `filesDir/vault.bin` | 加密的密码库 |
| `<备份文件夹>/appsettings.json` | 可选外挂配置（只读，不自动加载）；默认 `内部存储/backups/account` |
| `<备份文件夹>/*.acc` | 加密备份文件；默认 `内部存储/backups/account` |

## 构建

```sh
./test.sh unit      # 本地单元测试（72 个）
./build.sh          # debug APK 并安装到真机
./build.sh release  # 已签名 release APK
```

签名凭据从 `keystore.properties` 读取（不提交仓库）；文件缺失时 release 自动回退为未签名构建。Android Studio 直接打开项目即可。

## 架构

无 ViewModel、中央组装：`AccountApp` 是装配壳（路由 + 接线），各功能域状态收敛在 `runtime/` 状态容器（`SettingsContainer` 设置、`UnlockSession` 解锁会话/DEK、`BackupLocationState` 备份目录授权、`IdleLockHost` 空闲锁定接线、`AutofillBridge` 自动填充内存快照桥）；`page/` 页面为无状态 props + 回调（备份页经 `BackupContracts` 三接口与装配层解耦）；`security/` 密码学与规则（`Totp`/`IdleLock` 纯 JVM 可单测，`VaultStore` 走 Robolectric）、`service/` 系统自动填充（`AppAutofillService` 填充/保存管线、`AutofillAuthActivity` 认证回包、`AutofillMatcher` 共享匹配与数据集构建、`AutofillSelfHeal` 桥自愈）、`util/DomainCleaner` 域名规整（纯 JVM 可单测）、`data/` 模型与持久化、`ui/` 组件与主题。依赖方向单向：page/ui → runtime → security/data。
